# Modular Stock Buddy

Olá, preciso criar um sistema de controle de estoque de materiais do marketing da Modular. Para isso, preciso que tenha:
- painel para controle de estoque
- tela para adicionar novos materiais recebidos
- uma tela informando quantos materiais saíram e para qual unidade ou pessoa
- Cada material precisa de um Cód. do Produto, Descrição, Entradas, Saídas, Custo do produto na entrada, Saldo total do estoque, Status, Total Gasto, Total Comprado, Saldo Restante
- Uma tela que mostra a evolução do valor do produto/brinde
